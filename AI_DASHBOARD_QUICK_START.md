# 🚀 AI Dashboard Quick Start Guide

## Access the Dashboard

Navigate to: **`http://localhost:5173/ai-dashboard`**

## Prerequisites

1. **Connect Wallet** - You must have a connected wallet
2. **Set API Key** - Add OpenAI API key to `.env`:
   ```bash
   VITE_OPENAI_API_KEY=sk-your-key-here
   ```

## Dashboard Features

**AI Recommendations Section**
- Personalized NFT suggestions at the top
- Match scores (1-10) showing compatibility
- AI reasoning for each recommendation
- One-click "Rent Now" buttons

**Browse NFTs**
- View all available rentals

**AI Analysis Modal**
- Click any NFT to see detailed analysis

## Troubleshooting

### "OpenAI API key not found"
- Add `VITE_OPENAI_API_KEY` to `.env`
- Restart development server
- Reload page

### "Connect wallet" screen showing
- Make sure wallet is connected
- Check browser extension is installed
- Try refreshing the page

### Agents not activating
- Check OpenAI API key is valid
- Ensure sufficient API credits
- Check browser console for errors

### No recommendations showing
- Agents may be inactive
- Toggle agent activation
- Check network connection
- Verify API key has credits
